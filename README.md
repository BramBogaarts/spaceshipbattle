# spaceshipbattle
Webp2
Dit is een spaceship battle game die gemaakt is met PHP waar spaceships uitgerust met canons en turrets tegen elkaar strijden.

Technische vereisten:
PHP: 8.1.0 of hoger
Mysql
opdrachtprompt (om composers te installeren).
MAMP (om lokaal te werken).

installatie:
git clone: https://github.com/BramBogaarts/spaceshipbattle.git
cd "de locatie waar je de mappen wilt hebben"

Gebruik:
Open index.php in je browser
Het systeem creëert automatisch twee spaceships:
Millennium Falcon met canons
TIE-Fighter met turret
De battle start automatisch en toont:
Aanvallen per ronde
Resterende HP
Winnaar of gelijkspel
Database Management
Klik op de "database" knop in de interface
Hier kun je:
Nieuwe spaceships toevoegen aan de database
Bestaande spaceships bewerken
Spaceships verwijderen
Alle spaceships bekijken
Volledige database verwijderen (gebruik voorzichtig!)
